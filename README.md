# Seeing the Trees for the Forest: A Streamlit-based Application for Visualizing Forest Structure with LiDAR

An interactive Streamlit application for exploring three-dimensional forest structure using airborne light detection and ranging (LiDAR) data. 

This application allows users to visualize LiDAR point clouds and compare relative height metrics across three distinct forest types.

Access the web version here: https://forestlidar.streamlit.app/

# Overview 
## Background
Forest structure is a fundamental characteristic of plant communities and plays an essential role in ecosystem structure (Ehbrecht et al., 2021; Gamfeldt et al., 2012). Forest structure primarily refers to the three-dimensional (3-D) arrangement of vegetation in a forest, extending from the forest floor to the top of the canopy (Oliver and Larson, 1996). Light detection and ranging (LiDAR) technologies provide a powerful tool for retrieving forest structure measurements across multiple dimensions (Coops et al., 2021). However, processing and visualizing these data can require specialized software and substantial computational resources.

_Seeing the Trees for the Forest_ provides an accessible interface for exploring forest structure without requiring users to directly manipulate raw LiDAR datasets. This allows users to investigate the question: How do LiDAR-derived measurements of vertical forest structure vary across ecosystems with different vegetation types and climatic conditions?

## Methods
There are many different approaches for estimating forest structure from LiDAR, but for this app we focus on relative height (RHn), as it is applicable to both spaceborne and airborne platformsand have demonstrated relation to biomass and canopy volume (Lefsky 2002; Lim et al., 2003). RHn are defined as the distance between the elevations of detected ground return and the n% accumulated waveform energy, where n ranges from 1 to 100 (Duncanson et al., 2020).

To calculate RHn using discrete point cloud LiDAR, vertical return-density profiles are generated by binning LiDAR return heights into discrete height intervals and calculating the relative frequency of returns within each interval.

Three relative height metrics are calculated from the cumulative distribution of LiDAR return heights:

- **RH25**: Height below which 25% of returns occur.

- **RH50**: Height below which 50% of returns occur.

- **RH98**: Height below which 98% of returns occur.

Users can explore how these measurements change when restricting the vertical range of the point cloud.

# Getting Started
clone the repository:
```
git clone https://github.com/rgizzo/weblidar-forest-structure.git
cd weblidar-forest-structure
```

Create a virtual environment:
```
python -m venv .venv
```

Activate the environment and install the required libraries:
```
pip install -r requirments.txt
```

Launch the application 
```
streamlit run app.py
```
